# NEXA - AI Career Roadmap Generator

> 🚀 A personal learning project built to explore AI-powered resume analysis and career recommendation using modern web technologies.

---

## About

NEXA is an AI-powered web application that analyzes a user's resume and provides:

- Resume skill extraction
- Career recommendation
- Readiness score
- Skill gap analysis
- Personalized learning roadmap

This project was developed primarily to learn and practice:

- Full-stack application development
- FastAPI backend development
- Next.js frontend development
- Resume parsing
- Basic NLP concepts
- AI-based career recommendation systems

> **Note:** This is a personal learning project and is not intended to provide professional career advice. The recommendation logic is simplified and designed for educational purposes.

---

## Features

- Upload PDF Resume

## Installation

### Backend

```bash
cd backend

pip install -r requirements.txt

python -m uvicorn app:app --reload
```

Backend:

```
http://127.0.0.1:8000
```

---

### Frontend

```bash
cd frontend

npm install

npm run dev
```

Frontend:

```
http://localhost:3000
```
